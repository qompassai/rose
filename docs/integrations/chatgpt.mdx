ChatGPT Desktop includes Codex, OpenAI's desktop coding agent. Rose adds compatible local and cloud models to Codex's model picker alongside ChatGPT's native models.

## Prerequisites

- Rose v0.34.0 or newer

If ChatGPT is not installed, Rose offers to download it during setup.

## Connect ChatGPT

1. Open the Rose desktop app and select **Apps**.
2. Toggle **ChatGPT (Desktop)** to On.
3. Follow the setup prompts. If ChatGPT is already open, Rose asks to restart it before the new models appear.
4. Open the ChatGPT desktop app and use Codex mode.

## Choose models

Open Rose **Settings**, select **Apps**, then select ChatGPT. Choose up to five compatible local or cloud models and save your changes. Rose asks to restart ChatGPT when a model change needs one.

## Disconnect ChatGPT

Open Rose **Apps** and turn ChatGPT off. Rose restores ChatGPT's connection settings and usual profile. If ChatGPT is open, Rose asks to restart it so the change takes effect.

## Codex behavior and limits

- Only requests made with an Rose model go to Rose. ChatGPT's native models keep using their usual provider.
- Rose models are for Codex mode. Regular Chat and voice keep using their usual ChatGPT connection.
- Codex manages sessions. Rose routes model requests and compaction when Codex asks for it, but does not store ChatGPT sessions.
- Web search uses Rose's web-search service when you use an Rose model. It requires Rose sign-in and is limited to three calls per response.
