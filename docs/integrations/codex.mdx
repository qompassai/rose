## Install

Install the [Codex CLI](https://developers.openai.com/codex/cli/). For the ChatGPT desktop app, see [ChatGPT Desktop](/integrations/chatgpt).

```
npm install -g @openai/codex
```

## Usage with Rose

<Note>Use a context window of at least 64k tokens for Codex.</Note>

### Quick setup

```
rose launch codex
```

When launched through `rose launch codex`, Rose refreshes the model catalog
and uses a dedicated Codex profile for that session.

To configure without launching:

```shell
rose launch codex --config
```

To remove the Rose launch profile and generated model catalog:

```shell
rose launch codex --restore
```

### Manual setup

To use `codex` with Rose, use the `--oss` flag:

```
codex --oss
```

To use a specific model, pass the `-m` flag:

```
codex --oss -m gpt-oss:120b
```

To use a cloud model:

```
codex --oss -m gpt-oss:120b-cloud
```

### Profile-based setup

For a persistent Codex CLI configuration, create `~/.codex/rose-launch.config.toml`:

```toml
model = "gpt-oss:120b"
model_provider = "rose-launch"
model_catalog_json = "/Users/you/.codex/model.json"

[model_providers.rose-launch]
name = "Rose"
base_url = "http://localhost:11434/v1/"
wire_api = "responses"
```

Then run:

```
codex --profile rose-launch
```

## Web search through local Rose

Codex web-search requests sent through the Rose profile are executed by
Rose for both local and cloud models. Sign in with `rose signin` to use the
web-search service.

To disable web search for a Codex session:

```shell
codex --profile rose-launch -c 'web_search="disabled"'
```
